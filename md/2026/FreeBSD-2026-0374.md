# Weechat -- Multiple vulnerabilities
The Weechat project reports:

> Use-after-free and double free when a remote relay sends an event with
> an array as body.
>
> Use-after-free in the irc plugin when a batched message disconnects
> the server.
>
> Stack buffer overflow when building a JOIN command with channel keys.


## Affected packages
 - **weechat**
    - **Fixed:** 4.9.5
