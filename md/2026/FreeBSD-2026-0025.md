# zeek -- potential DoS vulnerability
Tim Wojtulewicz of Corelight reports:

> Zeek\'s HTTP analyzer can be tricked into interpreting
> Transfer-Encoding or Content-Length headers set in MIME entities
> within HTTP bodies and change the analyzer behavior.


## Affected packages
 - **zeek**
    - **Fixed:** 8.0.6
