# Mozilla -- Memory safety bugs
Mozilla reports:

> Memory safety bugs present in Firefox ESR, Firefox ESR , Thunderbird
> ESR, and Thunderbird. Some of these bugs showed evidence of memory
> corruption and we presume that with enough effort some of these could
> have been exploited to run arbitrary code.


## Affected packages
 - **firefox**
    - **Fixed:** 149.0.2,2
 - **firefox-esr**
    - **Fixed:** 140.9.1,2
 - **thunderbird**
    - **Fixed:** 149.0.2
 - **thunderbird-esr**
    - **Fixed:** 140.9.1
