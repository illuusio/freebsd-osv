# Unbound -- Multiple vulnerabilities
NLNetLabs reports:

> This release consolidates security fixes for issues reported over a
> period of time.
>
> - CVE-2026-97206, DoQ path-migration can lead to use-after-free on
>   multi-threaded deployments.
> - CVE-2026-50106, Possible insecure NXDOMAIN for non-existing records
>   under a configured island trust anchor underneath an insecure
>   parent.
> - CVE-2026-96405, Aggregate DNS name chained pointer decompression
>   work leads to degradation of service.
> - CVE-2026-109125, Possible cache poisoning vulnerability via a cache
>   side-channel exposed by 'unwanted-reply-threshold'.
> - CVE-2026-35501, Bypass of a configured island trust anchor
>   underneath an insecure parent from an attacker-controlled NSEC
>   record.


## Affected packages
 - **unbound**
    - **Fixed:** 1.26.2
