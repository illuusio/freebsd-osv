# Routinator -- CWE-20 Improper Input Validation
<https://www.nlnetlabs.nl/downloads/routinator/CVE-2026-49234.txt>
reports:

> When sending a specifically crafted non-UTF-8 string as select-asn
> query parameter to the /api/v1/origins endpoint, Routinator crashes.
> This only affects users who allow API access from untrusted networks.
>
> Thanks to [X41 D-Sec GmbH](https://www.x41-dsec.de/) for reporting the
> vulnerability.


## Affected packages
 - **routinator**
