# mail/mailpit -- Server-Side Request Forgery
Mailpit author reports:

> A Server-Side Request Forgery (SSRF) vulnerability exists in
> Mailpit\'s /proxy endpoint that allows attackers to make requests to
> internal network resources.
>
> The /proxy endpoint allows requests to internal network resources.
> While it validates http:// and https:// schemes, it does not block
> internal IP addresses, allowing attackers to access internal services
> and APIs.


## Affected packages
 - **mailpit**
    - **Fixed:** 1.28.1
