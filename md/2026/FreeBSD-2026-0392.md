# gitea -- Multiple vulnerabilities
Gitea reports

> This release addresses the following security vulnerabilities. Please
> upgrade as soon as possible.
>
> Unauthenticated arbitrary file read via the Org-mode #INCLUDE
> directive.
>
> Remote code execution via the diffpatch API through Git hook
> installation.


## Affected packages
 - **gitea**
    - **Fixed:** 1.27.1
