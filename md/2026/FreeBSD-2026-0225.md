# Grafana -- OpenFeature evaluation API reads input data with no bounds
https://grafana.com/security/security-advisories/cve-2026-27880 reports:

> The OpenFeature feature toggle evaluation endpoint reads unbounded
> values into memory, which can cause out-of-memory crashes.
