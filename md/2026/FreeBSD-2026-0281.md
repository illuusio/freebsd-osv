# Routinator -- CWE-22 Improper Limitation of a Pathname to a Restricted Directory ('Path Traversal')
<https://www.nlnetlabs.nl/downloads/routinator/CVE-2026-49233.txt>
reports:

> Routinator does not properly check the module component of rsync URIs,
> which are used to create the file system paths for the Routinator
> cache. This allows for path traversal by having a module name
> containing .., potentially providing an attacker access to the entire
> Routinator rsync cache.
>
> Thanks to [X41 D-Sec GmbH](https://www.x41-dsec.de/) for reporting the
> vulnerability.


## Affected packages
 - **routinator**
    - **Fixed:** 0.15.2
