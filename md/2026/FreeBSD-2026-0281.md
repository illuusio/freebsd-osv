# Routinator -- CWE-755 Improper Handling of Exceptional Conditions
<https://www.nlnetlabs.nl/downloads/routinator/CVE-2026-49232.txt>
reports:

> Routinator exits on any error when accepting incoming HTTP or RTR
> connections, including ones it can recover from such as running out of
> file descriptors. This condition can be triggered maliciously by an
> attacker by opening a large number of connections to the HTTP or RTR
> server. This only affects users that make their HTTP or RTR server
> available to untrusted networks.
>
> Thanks to [X41 D-Sec GmbH](https://www.x41-dsec.de/) for reporting the
> vulnerability.
