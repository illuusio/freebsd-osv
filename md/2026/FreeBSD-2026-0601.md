# anki -- Malicious APKG can lead to arbitrary code execution via iframes
Anki developers reports:

> On Anki Desktop, a crafted APKG can execute an arbitrary executable
> after either clicking Show in the import result, opening the imported
> deck or viewing a note in the editor.


## Affected packages
 - **anki**
    - **Fixed:** 26.09.4
