# Gitea -- multiple vulnerabilities
Gitea reports:

> This release contains fixes for 26 security issues, hardens issue
> searching that an unfiltered query no longer enumerates every public
> repository into the indexer filter and removes unsafe code from the
> internal private endpoints. Please upgrade as soon as possible.
