# MongoDB Server -- CWE-617: Reachable Assertion
https://jira.mongodb.org/browse/SERVER-101758 reports:

> A user with access to the cluster with a limited set of privilege
> actions can trigger a crash of amongod process during the limited and
> unpredictable window when the cluster is being promoted from a replica
> set to a sharded cluster. This may cause a denial of service by taking
> down the primary of the replica set.


## Affected packages
 - **mongodb80**
    - **Fixed:** 8.0.18
 - **mongodb70**
    - **Fixed:** 7.0.31
