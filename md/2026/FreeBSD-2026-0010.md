# libtasn1 -- Stack-based buffer overflow
oss-security@ list reports:

> Stack-based buffer overflow in libtasn1 version: v4.20.0. The function
> fails to validate the size of input data resulting in a buffer
> overflow in asn1_expend_octet_string.


## Affected packages
 - **libtasn1**
    - **Fixed:** 4.21.0
