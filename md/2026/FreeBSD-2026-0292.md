# ffmpeg -- Out-of-bounds write
https://code.ffmpeg.org/FFmpeg/FFmpeg/pulls/23159 reports:

> An out-of-bounds write vulnerability in FFmpeg\'s libavcodec library,
> specifically in the MagicYUV decoder, allows denial-of-service and, in
> some cases, can be exploited for remote code execution. This
> vulnerability is associated with the file libavcodec/magicyuv.C. This
> issue affects FFmpeg before version 8.1.2.


## Affected packages
 - **ffmpeg**
    - **Fixed:** 8.1.2,1
 - **ffmpeg4**
    - **Fixed:** 4.4.7
 - **ffmpeg6**
    - **Fixed:** 6.1.6
