# trafficserver -- multiple vulnerabilities
The Apache Traffic Server project published security advisories for
issues fixed in releases 10.1.1 through 10.1.5. They include request
smuggling and cache poisoning through malformed requests and responses,
memory corruption, and unauthenticated access in the experimental
plugins, which the port builds (tsmemcache, wasm, and magick with the
IMAGEMAGICK option).


## Affected packages
 - **trafficserver**
    - **Fixed:** 10.1.5
