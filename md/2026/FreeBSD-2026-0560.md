# p5-Starman -- multiple vulnerabilities
Starman project reports:

> \[SECURITY\]
>
> - Stream chunked request bodies to the temporary buffer instead of
>   holding whole chunks in memory (CVE-2026-115824)
> - Parse chunk-size lines in linear time with a 4 KiB length limit and
>   strict syntax; malformed lines get 400 (CVE-2026-115822)
> - Do not send a response body for HEAD requests or 1xx, 204 and 304
>   responses, on both the array and streaming paths (CVE-2026-115823)
> - Limit how long a request body may take to arrive: \--read-timeout
>   (default 5 seconds) now also applies to each wait for more of the
>   body, and the new \--body-timeout option limits the total time
>   (default 300 seconds; raise it or set it to 0 for slower uploads).
>   Expiry gets 408 (CVE-2026-115817)
> - Reject Transfer-Encoding other than \"chunked\" (400/501) and close
>   the connection after a request with both Transfer-Encoding and
>   Content-Length. Completes the fix for CVE-2026-40560


## Affected packages
 - **p5-Starman**
    - **Fixed:** 0.4019
