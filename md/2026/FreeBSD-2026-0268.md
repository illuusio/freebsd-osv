# Erlang/OTP -- FTP passive-mode client does not validate server response IP
https://github.com/erlang/otp/security/advisories/GHSA-24cv-hwgr-37fq
reports:

> The FTP client in passive mode did not validate the IP address
> returned in the server\'s response, allowing a compromised or
> malicious server to redirect the data connection to an arbitrary host.
> This enables server-side request forgery (SSRF) and FTP bounce
> attacks.
