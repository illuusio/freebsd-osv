# Erlang/OTP -- megaco flex scanner buffer overflow
https://github.com/erlang/otp/security/advisories/GHSA-7xgh-gmgf-q2g7
reports:

> A remote unauthenticated attacker can crash Erlang nodes running the
> megaco text codec with the flex scanner option by sending an
> H.248/Megaco message with a property parm name exceeding 452 bytes.
> The overflow occurs in a C linked-in driver, causing the entire BEAM
> VM process to terminate. It is reachable pre-authentication, as the
> flex scanner processes raw TCP payloads before protocol validation.
