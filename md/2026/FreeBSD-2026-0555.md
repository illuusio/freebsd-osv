# rustls-ffi -- Read after free
The RusTLS project reports:

> functions retained a reference to the caller\'s server_name buffer
> after returning, rather than copying it. The API documentation did not
> require the buffer to outlive the call and as a result if the caller
> freed or reused the buffer, later TLS processing read freed memory.
> \[GHSA-rc3f-4j82-cmrg\]


## Affected packages
 - **rustls-ffi**
    - **Fixed:** 0.15.7
