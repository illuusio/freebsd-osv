# net-mgmt/net-snmp -- Remote Code Execution (snmptrapd)
net-snmp development team reports:

> A specially crafted packet to an net-snmp snmptrapd daemon can cause a
> buffer overflow and the daemon to crash.


## Affected packages
 - **net-snmp**
    - **Fixed:** 5.9.5
