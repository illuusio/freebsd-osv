# MongoDB Server -- Multiple vulnerabilities
https://jira.mongodb.org/browse/SERVER-119981 reports:

> - Computing the MD5 checksum of a malformed BSON object under specific
>   conditions may cause loss of availability in MongoDB server.
> - An authorization flaw in the user management command could allow an
>   authenticated user to make limited changes to authentication-related
>   data associated with another user account. This could affect how
>   authentication is performed for the impacted account.


## Affected packages
 - **mongodb80**
    - **Fixed:** 8.0.21
