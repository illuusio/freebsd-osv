# redmine -- multiple vulnerabilities
Redmine reports:

> - High: ReDoS in wiki macro argument parsing (#44657). Affects 6.0.0
>   and later; fixed in 7.0.3, 6.1.6 and 6.0.12.
> - High: OAuth token scope is ignored in Project.allowed_to_condition
>   (#44625). Affects 6.1.0 and later; fixed in 7.0.3 and 6.1.6.
> - High: Private project names and role assignments leaked via GET
>   /groups/\<id\>.json?include=memberships (#44468). Fixed in 7.0.2,
>   6.1.5 and 6.0.12.
> - High: Private/invisible issue subjects leaked via REST API
>   include=children (#44467). Fixed in 7.0.2, 6.1.5 and 6.0.12.
> - Moderate: Reflected XSS in attachments#edit_all (unvalidated
>   back_url) (#44682). Fixed in 7.0.3, 6.1.6 and 6.0.12.
> - Moderate: OAuth token scopes are bypassed when creating projects
>   (#44644). Affects 6.1.0 and later; fixed in 7.0.3 and 6.1.6.
> - Low: validate_back_url accepts URLs that browsers resolve to another
>   host (#44683). Fixed in 7.0.3, 6.1.6 and 6.0.12.


## Affected packages
 - **redmine70**
    - **Fixed:** 7.0.3
 - **redmine61**
