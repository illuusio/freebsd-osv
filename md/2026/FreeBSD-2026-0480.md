# Fetchmail -- NTLM potential remote code execution
Fetchmail reports:

> \[CVE-2026-94184\]: Fetchmail\'s NTLM authentication client can in
> some cases be susceptible to a remote code execution from a malicious
> server when fetchmail is configured with the NTLM feature enabled,
> depending on build details. fetchmail 6.6.7 release candidates, 6.6.7
> and subsequent releases are unaffected.


## Affected packages
 - **fetchmail**
    - **Introduced:** 5.0.8
    - **Fixed:** 6.6.7
