# podman -- podman quadlet install --replace does not fully replace the old file
The Podman developers report:

> When running podman quadlet install \--replace to replace a Quadlet
> file, if the original Quadlet is larger than the new Quadlet, the file
> would not be truncated and content from the original would be
> preserved.


## Affected packages
 - **podman**
    - **Introduced:** 5.7.0
    - **Fixed:** 5.8.6
