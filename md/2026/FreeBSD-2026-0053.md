# mail/mailpit -- Server-Side Request Forgery (SSRF) via Link Check API
Mailpit author reports:

> The Link Check API (/api/v1/message/{ID}/link-check) is vulnerable to
> Server-Side Request Forgery (SSRF). The server performs HTTP HEAD
> requests to every URL found in an email without validating target
> hosts or filtering private/internal IP addresses. The response returns
> status codes and status text per link, making this a non-blind SSRF.
> In the default configuration (no authentication on SMTP or API), this
> is fully exploitable remotely with zero user interaction.


## Affected packages
 - **mailpit**
    - **Fixed:** 1.29.2
