# yt-dlp: Improper Neutralization of Special Elements
https://github.com/yt-dlp/yt-dlp/security/advisories/GHSA-6v4j-43gg-vj32
reports:

> yt-dlp and youtube-dl are command-line audio/video downloaders. Prior
> to 2026.7.4, the \--write-link, \--write-url-link, and
> \--write-desktop-link options can write .url or .desktop shortcut
> files using attacker-controlled webpage_url or filename metadata
> without sufficient validation or escaping, allowing malicious file://
> URI injection on Windows or newline-based desktop entry key injection
> on Linux that can execute commands if the generated shortcut is
> opened. This issue is fixed in version 2026.7.4.


## Affected packages
 - **yt-dlp**
    - **Fixed:** 2026.07.04
