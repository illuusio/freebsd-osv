# httpclient -- Improper Certificate Validation
MITRE reports:

> Apache Commons HttpClient 3.x, as used in \..., does not verify that
> the server hostname matches a domain name in the subject\'s Common
> Name (CN) or subjectAltName field of the X.509 certificate, which
> allows man-in-the-middle attackers to spoof SSL servers via an
> arbitrary valid certificate.


## Affected packages
 - **apache-commons-httpclient**
    - **Introduced:** 3.1
 - **jakarta-commons-httpclient**
    - **Introduced:** 3.1
