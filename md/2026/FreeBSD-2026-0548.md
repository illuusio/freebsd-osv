# vifm -- Unverified Ownership
https://hackmd.io/@1ExmmukzRMWN7B4gQ4W-4Q/SkX7Pmiofg reports:

> Vifm 0.8.1-beta through 0.14.4 reuses a pre-existing IPC FIFO in the
> shared temporary directory without checking ownership, allowing local
> users to execute commands as another user. Attackers can pre-create a
> world-writable vifm-ipc-vifm FIFO and write IPC packets with -c and !
> shell commands that execute with the victim\'s privileges.


## Affected packages
 - **vifm**
    - **Fixed:** 0.14.5
