# libXtst -- multiple vulnerabilities
X.Org reports:

> Multiple issues have been found in the X client library
> implementations published by X.Org for which we are releasing security
> fixes for.
>
> - CVE-2026-94286: Out-of-bounds read in libXtst\'s RECORD reply parser
> - CVE-2026-109088: libXtst RECORD EnableContext Reply Endless Loop


## Affected packages
 - **libXtst**
    - **Fixed:** 1.2.6
