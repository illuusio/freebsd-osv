# libexpat -- Improper Handling of Unicode Encoding
https://github.com/libexpat/libexpat/pull/1282 reports:

> Expat before 2.8.5 fails to validate that a high surrogate in UTF-16
> input is followed by a low surrogate, allowing malformed UTF-16
> sequences to be accepted. Attackers can supply UTF-16 encoded XML
> containing lone high surrogates that consume the following code unit,
> causing Expat to pass unpaired surrogates to applications built with
> XML_UNICODE and to silently replace input characters in other builds.


## Affected packages
 - **expat**
    - **Fixed:** 2.8.5
