# PowerDNS Authoritative Server -- Denial of Service vulnerability
PowerDNS Team reports:

> CVE ID: CVE-2026-73206\
> \
> A malicious server can send a crafted reply that leads to high
> resource utilization decompression name pointers in DNS packets.\
> \
> This is a multi-vendor issue. Multiple DNS vendors are releasing fixed
> version of their products.\
> \
> The remedy is: upgrade to a patched version. The patched version
> imposes limits on the number of decompression done for a single name
> and for a DNS packet as a whole.


## Affected packages
 - **powerdns**
    - **Fixed:** 5.1.5
