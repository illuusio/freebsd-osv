# Weechat -- Multiple vulnerabilities
The Weechat project reports:

> - core: integer overflow in dynamic strings when their size exceeds 4
>   GiB (GHSA-h394-85x4-68c7)
> - core: heap buffer overflow in charset conversion when the converted
>   string is more than 4 times longer than the input and contains
>   invalid chars (GHSA-q32h-5qvq-3936)
> - irc: limit number of prefix modes in PREFIX of message 005 to
>   prevent memory exhaustion
> - irc: escape \${ in values of variables \$nick, \$channel and
>   \$server in commands /allchan, /allpv and /allserv, to prevent
>   evaluation of untrusted values
> - irc: escape \${ in server options addresses, nicks, password and
>   autojoin set from an IRC URL (irc://\...), to prevent evaluation of
>   untrusted values
> - irc: escape \${ in channel names saved in server option autojoin, to
>   prevent evaluation of channel names received from the server (for
>   example on channel forward)
> - irc: heap buffer overflow in nick prefixes when the server sends an
>   empty PREFIX in message 005 and the connection is lost before
>   message 001 (GHSA-xj8h-x2w9-m8m6)
> - relay: limit size of HTTP headers received from a client to prevent
>   memory exhaustion (GHSA-h394-85x4-68c7)
> - relay: fix heap buffer overflow in path of hdata sent to clients
>   with \"weechat\" protocol (GHSA-8wr2-x42m-7fxv)


## Affected packages

    - **Fixed:** 4.10.2
