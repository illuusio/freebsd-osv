# uptime-kuma -- unauthenticated administrator account creation
CVE-2026-119552: Uptime Kuma through 2.5.8 contains a race condition in
the Socket.IO first-run setup handler that allows unauthenticated
attackers to create an additional administrator account. Attackers can
send concurrent setup requests during the bcrypt hashing window to
bypass the empty user table check, then modify monitors, API keys, and
enable disableAuth.


## Affected packages
 - **uptime-kuma**
