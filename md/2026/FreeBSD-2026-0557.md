# p5-MIME-Tools -- multiple vulnerabilities
MIME-tools project reports:

> Many security issues were addressed (see the following ten CVEs)
> Issues were brought to my attention, and patches supplied, by the
> CPANSec security group.
>
> - CVE-2026-116264 invalid parameter hides boundary/filename
> - CVE-2026-116265 RFC 2231 boundary skips ambiguity checks
> - CVE-2026-116266 boundary changed by decoding not flagged
> - CVE-2026-116267 indent stored per message per level
> - CVE-2026-116268 unclosed \"(\" comments backtrack CPU exhaustion
> - CVE-2026-116269 RFC 2231 language tag empties filename
> - CVE-2026-116270 each bad \"=?\" copies the input into \$@
> - CVE-2026-116271 FileUnder reuses a pre-created directory
> - CVE-2026-116272 comment hides a duplicate boundary
> - CVE-2026-116273 max_parts and max_depth unlimited


## Affected packages
 - **p5-MIME-Tools**
    - **Fixed:** 5.522,2
