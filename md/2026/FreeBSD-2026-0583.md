# libwasmtime -- Multiple vulnerabilities
Wasmtime development team reports:

> - wasi-sockets: UDP connect only required the address to be permitted
>   for sending or receiving, allowing guests to send datagrams to
>   addresses denied for UdpSend.
> - Cross-engine type confusion with host-created
>   struct-types-with-supertypes has been fixed.
> - Panic with typed functions with i31 or nullref arguments has been
>   fixed.
> - Unchecked memory usage in transferring borrowed resources between
>   components has been fixed.
> - Fixed a possibility of content-length being invalid or not matching
>   body length in wasi-http p2.
