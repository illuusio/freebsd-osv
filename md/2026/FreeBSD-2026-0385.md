# py-djangorestframework -- two vulnerabilities
Bruno Alla reports:

> - Potential bypass of Django \`DATA_UPLOAD_MAX_MEMORY_SIZE\` when
>   parsing oversized JSON and urlencoded request bodies via DRF
>   \`request.data\`
> - AdminRenderer may disclose GET-protected data when rendering invalid
>   write requests
