# FreeBSD -- Local privilege escalation via execve()
# Problem Description:

An operator precedence bug in the kernel results in a scenario where a
buffer overflow causes attacker-controlled data to overwrite adjacent
execve(2) argument buffers.

# Impact:

The bug may be exploitable by an unprivileged user to obtain superuser
privileges.
