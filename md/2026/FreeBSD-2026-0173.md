# FreeBSD -- pf can overflow the stack parsing crafted SCTP packets
# Problem Description:

Incorrect packet validation allowed unbounded recursion parsing SCTP
chunk parameters. This can eventually result in a stack overflow and
panic.

# Impact:

Remote attackers can craft packets which cause affected systems to
panic. This affects any system where pf is configured to process
traffic, independent of the configured ruleset.
