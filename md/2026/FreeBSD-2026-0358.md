# Mozilla -- Memory safety bugs
https://www.mozilla.org/en-US/security/advisories/mfsa2026-68/#CVE-2026-16412
reports:

> Memory safety bugs present in Firefox ESR 140.12 and Firefox 152. Some
> of these bugs showed evidence of memory corruption and we presume that
> with enough effort some of these could have been exploited to run
> arbitrary code.
