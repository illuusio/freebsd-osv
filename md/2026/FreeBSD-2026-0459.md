# mkvtoolnix -- Heap Buffer Overflow via avilib ODML Superindex Integer Wraparound
Moritz Bunkus reports:

> potential heap overflows/invalid memory access in the ODML index
> handling due to unsiged integer multiplication wrapping around
> (colloquially known as \"overflowing\") with specifically crafted AVI
> files. Affects only mkvmerge as the other tools do not read AVIs


## Affected packages
 - **mkvtoolnix**
    - **Fixed:** 102.0
