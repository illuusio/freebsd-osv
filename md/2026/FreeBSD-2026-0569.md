# MySQL 8.4 -- Multiple vulnerabilities
Oracle reports:

> The October 2026 Critical Patch Update contains 98 new security
> patches for Oracle MySQL, 29 of which may be remotely exploitable
> without authentication.
>
> The patches for MySQL Server 8.4 are contained in release 8.4.13. The
> most severe issue in the server itself can be exploited over a network
> without authentication and allows the server to be taken over.
>
> Two further issues listed by Oracle, in the bundled curl and OpenSSL
> copies, do not apply to these ports: they build against the curl and
> OpenSSL of the system.


## Affected packages
 - **mysql84-client**
    - **Fixed:** 8.4.13
 - **mysql84-server**
    - **Fixed:** 8.4.13
