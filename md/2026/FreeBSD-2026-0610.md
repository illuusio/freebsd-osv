# OpenEXR -- 3.4.18 fixes two vulnerabilities
Cary Phillips reports:

> - CVE Pending (GHSA-PP92-4RV3-WFQ6): A signed-int data-window-origin
>   overflow in the OpenEXRUtil Image API turns Imf::loadImage into an
>   attacker-steered out-of-bounds write.
> - CVE Pending (GHSA-2V77-PVHX-25C3): Integer overflow in legacy
>   OpenEXR.OutputFile.writePixels() causes heap over-read.


## Affected packages
 - **openexr**
    - **Fixed:** 3.4.18
