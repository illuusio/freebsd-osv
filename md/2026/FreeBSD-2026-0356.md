# mailpit -- WebSocket origin check bypass via percent-encoded path
Mailpit author reports:

> The cross-site WebSocket hijacking fix was reimplemented as an origin
> check gated on a raw-URI prefix test, but Go\'s ServeMux routes on the
> percent-decoded path, so requesting /%61pi/events reaches the
> WebSocket handler while skipping the only origin control, and the
> upgrader itself accepts every origin.


## Affected packages
 - **mailpit**
    - **Fixed:** 1.30.6
