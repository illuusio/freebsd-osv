# xrdp -- remote code execution
Denis Skvortsov, Security Researcher at Kaspersky reports:

> xrdp before v0.10.5 contains an unauthenticated stack-based buffer
> overflow vulnerability. The issue stems from improper bounds checking
> when processing user domain information during the connection
> sequence. If exploited, the vulnerability could allow remote attackers
> to execute arbitrary code on the target system.


## Affected packages
 - **xrdp**
    - **Fixed:** 0.10.5
