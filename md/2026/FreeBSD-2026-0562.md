# Pillow -- multiple vulnerabilities
The Pillow project published security advisories for issues fixed in
release 13.0.0. They include an argument injection in the Ghostscript
call used for EPS images, heap buffer overflows in several image
decoders that can lead to code execution, and infinite loops and
unbounded memory use when opening crafted image files.
