# ISC KEA -- Stack overflow in Kea daemons
Internet Systems Consortium, Inc. reports:

> Sending a maliciously crafted message to the kea-ctrl-agent,
> kea-dhcp-ddns, kea-dhcp4, or kea-dhcp6 daemons over any configured API
> socket or HA listener can cause the receiving daemon to exit with a
> stack overflow error.


## Affected packages
 - **kea**
    - **Introduced:** 2.6.0
    - **Fixed:** 2.6.5
    - **Introduced:** 3.0.0
    - **Fixed:** 3.0.3
