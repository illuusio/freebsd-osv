# nginx-devel -- multiple vulnerabilities
The nginx project reports:

> nginx 1.31.0 fixes multiple security issues affecting HTTP/2 proxying,
> rewrite handling, SCGI/uWSGI response handling, charset conversion,
> HTTP/3 connection migration, and OCSP resolver response processing.


## Affected packages
 - **nginx-devel**
    - **Fixed:** 1.31.0
