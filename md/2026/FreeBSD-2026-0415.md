# FreeBSD -- Use-after-free in unix SOCK_STREAM message handling
# Problem Description:

The SOCK_STREAM receive path in the unix socket implementation failed to
fully detach control messages from the socket buffer before processing
them. Some error paths would free those messages, leaving freed data
mbufs in the receive socket buffer.

# Impact:

An unprivileged local user can exploit this use-after-free to escalate
privileges.


## Affected packages
 - **FreeBSD-kernel**
    - **Introduced:** 15.1
    - **Fixed:** 15.1_3
    - **Introduced:** 15.0
    - **Fixed:** 15.0_13
