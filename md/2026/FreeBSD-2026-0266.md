# Erlang/OTP -- SFTP READLINK discloses server filesystem paths
https://github.com/erlang/otp/security/advisories/GHSA-pv7g-pjrq-x2fh
reports:

> The SSH SFTP daemon\'s handling of SSH_FXP_READLINK returned symbolic
> link targets containing the server\'s absolute filesystem path,
> disclosing the backend root prefix to clients. The handler now strips
> the backend root prefix from symlink targets before returning them.

 - **erlang-runtime27**
