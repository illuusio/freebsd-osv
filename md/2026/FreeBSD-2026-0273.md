# h2o -- stack overflow serving static files on musl libc
h2o project reports:

> When serving static files, h2o can allocate a file path on the stack
> using alloca. On systems using musl libc, a large allocation can
> exceed the default pthread stack size and crash the server, causing a
> denial of service.


## Affected packages
 - **h2o**
    - **Fixed:** 20260609
