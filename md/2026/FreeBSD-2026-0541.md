# jackson-core -- denial of service
The Jackson project reports:

> CVE-2026-89407: NumberInput.looksLikeValidNumber() pre-validates
> stringified numbers with PATTERN_FLOAT, whose adjacent quantifiers
> allow catastrophic backtracking on crafted input.
>
> CVE-2026-89425: UTF8DataInputJsonParser builds the offending token
> text for an error message in a loop without an upper bound, so it
> ignores maxErrorTokenLength. The other three parser implementations
> are not affected.


## Affected packages
 - **jackson-core**
    - **Fixed:** 2.22.3
