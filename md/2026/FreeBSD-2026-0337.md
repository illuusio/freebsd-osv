# nginx -- multiple vulnerabilities
The nginx development team reports:

> Buffer overflow when using map and regex (CVE-2026-42533). Severity:
> major.
>
> Memory disclosure when using ngx_http_slice_module (CVE-2026-60005).
> Severity: medium.
>
> Use-after-free when using ngx_http_ssi_module (CVE-2026-56434).
> Severity: medium.


## Affected packages
 - **nginx**
    - **Fixed:** 1.30.4,3
 - **nginx-devel**
    - **Fixed:** 1.31.3
