# py-mkdocs-material -- DOM XSS vulnerability
Martin Donath reports:

> Material for MkDocs 7.2.0 through 9.7.6 contains a DOM-based
> cross-site scripting vulnerability in the optional search.suggest
> feature. A crafted q URL parameter could execute JavaScript in the
> documentation site\'s origin after user interaction.
