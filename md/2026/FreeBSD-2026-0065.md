# OpenSSL -- key agreement vulnerability
The OpenSSL project reports:

> TLS 1.3 server may choose unexpected key agreement group (Low)
>
> An OpenSSL TLS 1.3 server may fail to negotiate the expected preferred
> key exchange group when its key exchange group configuration includes
> the default by using the \"DEFAULT\" keyword.


## Affected packages
 - **openssl35**
    - **Fixed:** 3.5.5_1
 - **openssl36**
    - **Fixed:** 3.6.1_1
