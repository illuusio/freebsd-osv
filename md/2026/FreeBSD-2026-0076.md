# FreeBSD -- Remote denial of service via null pointer dereference
# Problem Description:

On a system exposing an NVMe/TCP target, a remote client can trigger a
kernel panic by sending a CONNECT command for an I/O queue with a bogus
or stale CNTLID.

# Impact:

An attacker with network access to the NVMe/TCP target can trigger an
unauthenticated Denial of Service condition on the affected machine.


## Affected packages
 - **FreeBSD-kernel**
    - **Introduced:** 15.0
    - **Fixed:** 15.0_5
