# phpMyAdmin -- Multiple vulnerabilities, no fix available
VulnCheck reports:

> Seven vulnerabilities in phpMyAdmin up to and including 5.2.3 were
> published on 2026-10-30. The most severe of them, an authentication
> bypass, is in the WebAuthn second factor: assertion signatures are
> never verified against the stored public keys, so an attacker who
> already has the MySQL credentials of a victim can skip the second
> factor.
>
> The others are a server-side request forgery in setup/validate.php,
> which needs no authentication at all and can be used to probe internal
> hosts and ports; the removal of two- factor authentication without
> re-authentication; SQL injection in Central Columns and in the
> Designer, both running with controluser privileges; stored cross-site
> scripting in the Designer history; and a missing cross-site request
> forgery token.
>
> There is no fixed release. The phpMyAdmin project has published
> neither a security announcement nor a new version, and only the
> request forgery has a fix in the development branch so far.
