# nginx -- buffer overflow when using ngx_http_v3_module
The nginx development team reports:

> Buffer overflow when using ngx_http_v3_module (CVE-2026-90439).
> Severity: medium.
>
> A heap memory buffer overflow might occur in a worker process under
> certain configurations when using HTTP/3 with OpenSSL 3.5.0 and
> earlier.


## Affected packages
 - **nginx**
    - **Fixed:** 1.30.5,3
 - **nginx-devel**
    - **Fixed:** 1.31.6
