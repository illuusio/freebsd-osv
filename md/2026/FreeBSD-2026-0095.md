# Mozilla -- Memory safety bugs
https://bugzilla.mozilla.org/buglist.cgi?bug_id=2022369%2C2023026%2C2023545%2C2023555%2C2023958%2C2025422%2C2025468%2C2025492%2C2025505
reports:

> Memory safety bugs present in Firefox ESR 140.9.0, Thunderbird ESR
> 140.9.0, Firefox 149.0.1 and Thunderbird 149.0.1. Some of these bugs
> showed evidence of memory corruption and we presume that with enough
> effort some of these could have been exploited to run arbitrary code.


## Affected packages
 - **firefox**
    - **Fixed:** 149.0.2,2
 - **firefox-esr**
    - **Fixed:** 140.9.1,2
 - **thunderbird**
    - **Fixed:** 140.9.1
