# mail/mailpit -- Incomplete SSRF protection in Link Check API via uncovered IPv6 forms
Mailpit authorreports:

> The tools.IsInternalIP deny-list relies on Go\'s stdlib classification
> helpers (IsLoopback, IsPrivate, IsLinkLocalUnicast,
> IsLinkLocalMulticast, IsUnspecified, IsMulticast) plus an inline CGNAT
> range, but those helpers do not match two classes of IPv6 address that
> should be blocked for SSRF purposes
