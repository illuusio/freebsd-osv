# metasploit -- multiple vulnerabilities
Rapid7 published security advisories for issues fixed in releases 6.5.2
through 6.5.7. The credential endpoint of the msf-ws REST API is
reachable without authentication, authentication in the JSON-RPC service
is skipped when the database health check fails, a post module writes
files outside the loot directory through a crafted path, and requests
follow HTTP redirects and FTP PASV responses to arbitrary hosts.


## Affected packages
 - **metasploit**
    - **Fixed:** 6.5.7
