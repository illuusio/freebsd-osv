# Drupal 10 and 11 -- remote code execution
Drupal core reports:

> A remote code execution vulnerability exists within the Field UI
> module in Drupal core.
>
> The vulnerability is not directly exploitable with core alone, but
> multiple serious exploit paths exist with contributed modules. At
> least one known exploit path does not require authentication. Custom
> code may also expose the vulnerable functionality.
>
> The vulnerability can be mitigated by uninstalling the core Field UI
> module (field_ui), which will provide protection while sites are
> updated.


## Affected packages
 - **drupal11**
    - **Introduced:** 11.4.0
    - **Fixed:** 11.4.10
 - **drupal10**
    - **Fixed:** 10.6.19
