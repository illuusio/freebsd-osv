# FreeBSD -- IPv6 UDP sendto(2) bypasses jail loopback restriction
# Problem Description:

The IPv6 UDP send path for unconnected sockets did not apply the jail
policy of rewriting a loopback destination address to the jail\'s
primary IPv6 address.

# Impact:

A process in a classic (non-VNET) jail can send UDP datagrams to
services listening on the host\'s IPv6 loopback address, bypassing jail
network isolation.
