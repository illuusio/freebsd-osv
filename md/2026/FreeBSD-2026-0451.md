# znc -- multiple vulnerabilities

> CVE-2026-82373: Use-after-free when unloading modules, triggered by
> unprivileged users. To mitigate, set DenyLoadMod to true.

> IRC server.

> CVE-2020-11022, CVE-2020-11023: Updated the old bundled vulnerable
> version of jQuery to 3.5.1.
