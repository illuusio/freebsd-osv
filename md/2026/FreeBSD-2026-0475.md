# RusTLS FFI -- plaintext TLS handshake vulnerability
The RusTLS project reports:

> TLS 1.3 handshake message processing could allow a broken peer to send
> plaintext handshake messages where an encrypted one is expected
> without rustls rejecting the connection


## Affected packages
 - **rustls-ffi**
    - **Fixed:** 0.15.4
