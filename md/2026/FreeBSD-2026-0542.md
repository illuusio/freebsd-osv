# jackson-databind -- denial of service
The Jackson project reports:

> CVE-2026-91776: TypeDeserializerBase caches the resolved deserializer
> under the raw, attacker supplied type id. With name based polymorphism
> and a fallback, every unrecognized type id adds an entry and the cache
> grows without bound.
>
> CVE-2026-91777: forward reference completion for JsonIdentityInfo
> object ids scans the pending reference accumulator for every resolved
> id, which is quadratic in the number of references.


## Affected packages
 - **jackson-databind**
    - **Fixed:** 2.22.3
