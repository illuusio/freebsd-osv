# Elixir -- Denial of service via unbounded integer parsing in Version
PJUllrich reports:

> The Version module parses numeric version components without length
> limits. Untrusted input can trigger creation of arbitrary-precision
> integers, causing CPU and memory exhaustion.


## Affected packages
 - **elixir**
    - **Introduced:** 1.5.0
    - **Fixed:** 1.19.5
