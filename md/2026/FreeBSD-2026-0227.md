# Grafana -- Grafana MSSQL Data Source Plugin: Restriction Bypass Leading to OOM DoS
https://grafana.com/security/security-advisories/cve-2026-33375 reports:

> The Grafana MSSQL data source plugin contains a logic flaw that allows
> a low-privileged user (Viewer) to bypass API restrictions and trigger
> a catastrophic Out-Of-Memory (OOM) memory exhaustion, crashing the
> host container.
