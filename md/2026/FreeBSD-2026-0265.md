# Erlang/OTP -- TLS distribution check_ip flag does not enforce same-LAN constraint
https://github.com/erlang/otp/security/advisories/GHSA-gp7x-mfv6-52cv
reports:

> Erlang distribution over TLS run with the kernel check_ip flag now
> properly enforces connecting nodes to be on the same LAN. Previously
> the constraint was not enforced.


## Affected packages
 - **erlang-runtime27**
    - **Fixed:** 27.3.4.13
 - **erlang-runtime28**
    - **Fixed:** 28.5.0.2
 - **erlang-runtime29**
    - **Fixed:** 29.0.2
