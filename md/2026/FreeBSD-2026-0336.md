# liboqs -- Multiple vulnerabilities
The OpenQuantumSafe project reports:

> - uninitialized encaps_derand pointer dereference
> - out-of-bounds read in XMSS/XMSS\^MT signature verification
> - Integer underflow in CROSS crypto_sign_open()
> - incorrect array size when calling secure_clean
> - Implemented optimization barrier OQS_MEM_BLACK_BOX and applied to
>   ct_select in FrodoKEM


## Affected packages
 - **liboqs**
    - **Fixed:** 0.16.0
