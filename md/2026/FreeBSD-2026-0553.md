# ImageMagick7 -- multiple vulnerabilities
The ImageMagick project published security advisories for issues fixed
in releases 7.1.2-26 through 7.1.2-34. They include heap buffer
overflows, use-after-free, out-of-bounds reads, integer overflows,
division by zero, memory leaks and security policy bypasses in various
coders and in the command-line interface. A crafted image file can crash
the process, disclose memory contents or circumvent the configured
security policy.


## Affected packages
 - **ImageMagick7**
    - **Fixed:** 7.1.2.34
 - **ImageMagick7-nox11**
    - **Fixed:** 7.1.2.34
