# miniupnpd -- Integer underflow in SOAPAction header parsing
An integer underflow in the SOAPAction header parsing in
ParseHttpHeaders() lets a remote attacker trigger an out-of-bounds read
by sending a malformed SOAPAction header containing a single quote. This
can crash miniupnpd or disclose memory beyond the HTTP request buffer.


## Affected packages
 - **miniupnpd**
    - **Fixed:** 2.3.10,1
