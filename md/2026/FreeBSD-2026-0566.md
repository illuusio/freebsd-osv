# MySQL Connectors -- Multiple vulnerabilities
Oracle reports:

> The October 2026 Critical Patch Update contains 98 new security
> patches for Oracle MySQL, 29 of which may be remotely exploitable
> without authentication.
>
> Eight of them affect the MySQL Connectors. The most severe, in
> Connector/J, can be exploited over a network without authentication.
> The fixes are contained in release 26.10.0 of each connector.


## Affected packages
 - **mysql-connector-c++**
    - **Fixed:** 26.10.0
 - **mysql-connector-j**
    - **Fixed:** 26.10.0
 - **mysql-connector-odbc**
    - **Fixed:** 26.10.0
 - **py-mysql-connector-python**
    - **Fixed:** 26.10.0
