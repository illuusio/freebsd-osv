# freenginx -- TLS session ticket key left uninitialized
The freenginx project reports:

> One of the keys was left uninitialized when using automatic rotation
> of TLS session ticket keys, making it possible to forge a session and
> bypass client certificate verification (CVE-2026-97629).


## Affected packages
 - **freenginx**
    - **Fixed:** 1.30.2
