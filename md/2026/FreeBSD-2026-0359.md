# Mozilla -- Memory safety bugs
https://www.mozilla.org/en-US/security/advisories/mfsa2026-68/#CVE-2026-16360
reports:

> Memory safety bugs present in Firefox ESR 115.37, Firefox ESR 140.12
> and Firefox 152. Some of these bugs showed evidence of memory
> corruption and we presume that with enough effort some of these could
> have been exploited to run arbitrary code.


## Affected packages
 - **firefox**
    - **Fixed:** 152.0.0,2
 - **firefox-esr**
    - **Fixed:** 140.12,2
 - **thunderbird**
    - **Fixed:** 140.13
