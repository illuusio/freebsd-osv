# mutt -- Heap out-of-bounds write via crafted Content-Header line
Kevin J. McCarthy reports:

> Fixing an OOB heap write. This is triggered by a specially crafted
> Content-Header line in an email that is used as a template for a new
> email, via \<resend-message \>. Thanks to Calif.io, in collaboration
> with Anthropic for sending me a detailed write up and suggested patch.
