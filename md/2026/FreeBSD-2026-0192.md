# Vulnerability found in Expat
> Expat 2.8.1 was released yesterday. The key motivation for cutting a
> release and doing so now was:
>
> Fixing vulnerability CVE-2026-45186 that allows easy denial of
> service.
>
> See also https://github.com/libexpat/libexpat/pull/1216


## Affected packages
 - **expat**
    - **Fixed:** 2.8.1
 - **linux-c7-expat**
    - **Fixed:** 2.8.1
 - **linux-rl9-expat**
    - **Fixed:** 2.8.1
