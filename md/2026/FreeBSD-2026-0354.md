# Erlang/OTP -- TLS denial of service using invalid certificate chains
https://github.com/erlang/otp/security/advisories/GHSA-r5jr-mq46-vmhw
reports:

> A TLS/DTLS peer can crash the remote node by sending a certificate
> chain containing two mutually cross-signed certificates in unordered
> form. When the receiving side attempts to build a valid chain path, it
> enters unbounded recursion between the two certificates (A issues B, B
> issues A) with no cycle detection or depth limit. The call stack and
> chain accumulator grow without bound until the process exhausts
> available memory and the BEAM node crashes.
