# Forgejo -- Symbolic Link (Symlink) Following
https://codeberg.org/forgejo/forgejo/src/branch/forgejo/release-notes-published/13.0.2.md
reports:

> Forgejo before 13.0.2 allows attackers to write to unintended files,
> and possibly obtain server shell access, because of mishandling of
> out-of-repository symlink destinations for template repositories. This
> is also fixed for 11 LTS in 11.0.7 and later.


## Affected packages
 - **forgejo**
    - **Fixed:** 13.0.2
